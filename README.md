# Soft Sensor Calibration

Código MATLAB para caracterizar un sensor hidráulico blando mediante su curva presión–deformación. Procesa los datos experimentales de extensión y contracción, calcula deformación y presión, analiza la histéresis del sensor y ajusta un modelo lineal para obtener su sensibilidad y el error (RMSE) de la calibración.
